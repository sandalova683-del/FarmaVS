# FormulaVS 4.0 native integration

The repository contains the native health implementation as a reusable Capacitor plugin source under `packages/formulavs-health`.

## iOS

1. Generate the Capacitor iOS project with `npx cap add ios`.
2. Add `ios/App/App/Plugins/FormulaVSHealthPlugin.swift` to the app target (it is copied from the reusable plugin source).
3. Enable **HealthKit** capability in the Xcode target.
4. Add `NSHealthShareUsageDescription` to the app Info.plist, for example:
   `FormulaVS uses your health data to automatically record your daily step count.`
5. Build on a real iPhone. HealthKit data is not available in the iOS simulator in the same way as a physical device.

## Android

1. Generate the Capacitor Android project with `npx cap add android`.
2. Add `packages/formulavs-health/android` as the native plugin module or copy the plugin class into the Android app's plugin source set.
3. Add the dependency:
   `androidx.health.connect:connect-client:1.1.0`
4. Declare `android.permission.health.READ_STEPS` and the Health Connect provider query.
5. Build and run on an Android device/emulator with Health Connect available.
6. Complete the Health Connect app declaration/review required by Google Play before production distribution.

## Permissions

Only step-count read access is requested. There is no write permission in FormulaVS 4.0.

## Plugin registration

The native class must be registered with the Capacitor bridge. Templates are included in:

- `ios/App/App/FormulaVSHealthRegistration.swift`
- `android/app/src/main/java/com/formulavs/health/FormulaVSHealthRegistration.kt`

Use the registration mechanism generated by the Capacitor version in the native project.
